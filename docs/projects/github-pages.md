# Publish a static site with GitHub Pages

> **Category:** Project · **Tags:** `github`, `deployment`, `static site` · **Difficulty:** Beginner  
> **Last updated:** 2026-11-20

## Overview

GitHub Pages can serve a static site directly from a repository. This project uses root-relative file organization with relative links and has no build step.

## Publish

1. Commit the site files to the repository's `main` branch.
2. In repository settings, open **Pages**.
3. Choose deployment from a branch, then select `main` and `/ (root)`.
4. Save and wait for the deployment to complete.
5. Open the published URL and check navigation, search, styles and document links.

## Before sharing

- Confirm all content is appropriate for a public repository.
- Keep asset and document links relative so project pages work under a repository path.
- Check the Pages build status after future changes.
- Remember that static pages are public when hosted in a public repository.
