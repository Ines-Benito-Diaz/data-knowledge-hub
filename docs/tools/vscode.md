## Overview

VS Code can keep editing, search, source control and terminal work in one lightweight workspace.

## Useful navigation

| Action | macOS | Windows / Linux |
|---|---|---|
| Quick Open | `⌘ P` | `Ctrl P` |
| Command Palette | `⌘ Shift P` | `Ctrl Shift P` |
| Search in files | `⌘ Shift F` | `Ctrl Shift F` |
| Toggle terminal | `` Ctrl ` `` | `` Ctrl ` `` |
| Markdown preview | `⌘ Shift V` | `Ctrl Shift V` |

## Workspace practices

- Open the repository folder as the workspace root.
- Keep project-specific recommendations in `.vscode/extensions.json` only when useful to collaborators.
- Use the integrated terminal for commands that should run from the project root.
- Review keyboard shortcuts in the Command Palette; keymaps and keyboard layouts can change defaults.
