# 💻 Shortcuts Cheat Sheet
## VS Code Shortcuts — macOS & Windows

A practical reference for coding faster, navigating VS Code like a pro, and keeping your hands off the mouse.

**Key legend**

- macOS: `⌘` Command · `⌥` Option · `⇧` Shift · `⌃` Control
- Windows: `Ctrl` Control · `Alt` · `Shift` · `Win` Windows

## 4. Multi-cursor editing

One of the best productivity features in VS Code!

| Action | macOS | Windows |
|---|---|---|
| Add cursor with mouse | `⌥ + Click` | `Alt + Click` |
| Select next matching occurrence | `⌘ + D` | `Ctrl + D` |
| Select all matching occurrences | `⌘ + Shift + L` | `Ctrl + Shift + L` |
| Add cursor to line below | `⌥ + Shift + ↓` | `Ctrl + Alt + ↓` |
| Add cursor to line above | `⌥ + Shift + ↑` | `Ctrl + Alt + ↑` |
| Exit multi-cursor mode | `Esc` | `Esc` |

**Example:** You have a variable named `user_name` repeated 10 times. Select it, press `⌘ + Shift + L` on Mac or `Ctrl + Shift + L` on Windows, and edit all 10 occurrences simultaneously.

## 8. Terminal shortcuts

| Action | macOS | Windows |
|---|---|---|
| Open/close integrated terminal | `Ctrl + \`` | `Ctrl + \`` |
| Create new terminal | `Ctrl + Shift + \`` | `Ctrl + Shift + \`` |
| Copy selected text | `⌘ + C` | `Ctrl + C` |

**Important:** In a terminal, `Ctrl + C` usually interrupts a running process. In the editor, `⌘ + C` on Mac or `Ctrl + C` on Windows copies selected text.

## Notes & references

- Shortcuts assume the default VS Code macOS and Windows keymaps.
- Some shortcuts may vary depending on keyboard layout, extensions, operating system settings or custom keybindings.
- On some Mac keyboards, function keys require the `Fn` key.
- Windows terminal copy/paste behavior can depend on the selected terminal and its configuration.
